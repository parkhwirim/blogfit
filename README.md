# ✍️ 블로그핏 (BlogFit) - 네이버 블로그 상위노출 키워드 & 글자수 진단기

> **네이버 블로그 C-Rank & DIA 알고리즘 최적화 글자수·키워드 밀도 분석 툴**  
> Google AdSense 수익화 최적화 마이크로 웹 서비스

---

## 🚀 주요 기능

1. **📊 실시간 글자수 진단**
   - **공백 제외 글자수** (네이버 로직 기준 1,500~2,500자 상위 노출 최적 구간 프로그레스 바)
   - **공백 포함 글자수**, 단어 수, 문단 수 실시간 카운트
   - 모바일 체류시간 가이드 (예상 읽는 시간 산출)

2. **🚦 타겟 키워드 3~7회 황금 반복 신호등**
   - 0회: 🔴 누락 경고
   - 1~2회: 🟡 부족 경고 (1~2회 추가 권장)
   - 3~7회: 🟢 **황금 최적 구간** 달성
   - 8회 이상: 🚨 **과다 어뷰징(도배) 경고** (검색 누락 방지)

3. **🔝 본문 최다 빈출 단어 TOP 10**
   - 불용어(조사, 접속사 등)를 자동 제거하고 본문 핵심 명사/키워드 빈도수 태그 클라우드 표시

4. **👀 본문 형광펜 하이라이트 모드**
   - 타겟 키워드가 본문 전반에 골고루 분산되어 있는지 한눈에 시각화

5. **✅ 발행 전 필수 상위노출 체크리스트**
   - 제목 키워드 포함, 1500자 달성, 사진 개수, 모바일 가독성 줄바꿈 자가 진단

6. **💰 구글 애드센스(Google AdSense) 최적화 세팅**
   - 상단/하단 반응형 광고 슬롯 완비
   - 개인정보처리방침 & 이용약관 모달 탑재 (100% 브라우저 로컬 연산, 서버 전송 0건)
